# パーツ選び画面：矢印で送る選び方と機体の見本（設計メモ）

## ねらい
最初のパーツ選びで、15枚のカードが横に並んで見づらい。種類ごとに1枚ずつ大きく見せて矢印で送り、
選んだ3つで組んだ機体と性能を右側でまとめて見られるようにする。

## 決めたこと（依頼者）
- 種類ごとに、真ん中に大きいカード1枚・左右に隣のカードが少しのぞく形にし、◀▶で送る
- 見出しにマウスを合わせた種類だけ開き、ほかの種類はカードを隠して文字だけにする
- 真ん中に来たカードがそのまま選ばれる
- 右側に、選んだパーツで組んだ回る機体の見本、その下にフレーム・武器・スキルの詳しい性能の一覧

## 決めたこと（実装側の判断）
- 開いた段はマウスが離れても開いたまま。最初はフレームが開いている
- 閉じた段の見出しにも「武器：ハンマー」のように今の選択を出す
- 両脇のカードを押しても1つ送れる。端は輪になる（5枚目の次は1枚目）。送るときは短く横に滑らせる
- キーボード：←→で送る、↑↓で開く段を替える
- 最初から各種類の1枚目を選んだ状態にする（すぐ決定できる）
- フレームの枠より多いパーツは見本に付けず、一覧に「このフレームには付けられない」と出す
- 下の「現在の構成」の欄と吹き出しは右の一覧と重なるので、この画面では使わない（吹き出しはほかの画面で使うので残す）
- 見本・カードの大きさ、送る速さは view/look.gd に置く

## 進め方の候補
- A. 今の画面を作り直し、段の部品（part_carousel.gd）と右の見本（build_preview.gd）を新しく作る ← 採用
- B. 吹き出しを右に固定して使い回す：1つのパーツしか見せられず、3つ全部を見せる今回の形に合わない

## 作るもの
- view/draft/part_carousel.gd（新規）：1種類分の段。見出し・◀▶・カード・選択の通知
- view/draft/build_preview.gd（新規）：回る機体の見本と性能の一覧
- view/draft/draft_screen.gd：作り直す。操作は今までどおり MatchSession の draft_pick / finish_draft だけ
- tests/test_ui_flow.gd：パーツ選びの確かめを書き直す（送ると選択が変わる、段が1つだけ開く、見本が選んだ構成になる）
